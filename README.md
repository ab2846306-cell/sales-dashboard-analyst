# Sales Dashboard Analyst

Exploratory sales analysis of the Superstore dataset (9,800 orders) using Python.

## Tools
Python, Pandas, NumPy, Matplotlib, Seaborn, Jupyter

## What I did
- Cleaned data: converted dates, removed duplicates, filled missing postal codes
- Analyzed sales by category, region, segment, product and year
- Created charts saved in the images folder

## Key findings
- Technology is the top category by sales
- West is the top region; South is the weakest
- Consumer segment contributes about 51% of sales
- Sales grew strongly from 2016 to 2018

## How to run
1. Install: pip install pandas numpy matplotlib seaborn jupyter
2. Open notebooks/analysis.ipynb and run all cells
